# 🌐 Isaac Ramos — Portfolio

> 🔗 **Site ao vivo:** [https://izackzin.github.io/Portfolio-Isaac-Ramos/](https://izackzin.github.io/Portfolio-Isaac-Ramos/)

Portfólio web pessoal de **Isaac Ramos** — estudante de Engenharia de Software na UniCEUB, desenvolvedor full stack, designer gráfico desde os 13 anos, fundador da **Osprey Aerial Solutions** e entusiasta de tecnologia e criatividade.

---

## 🚀 Visão Geral

Site single-page com tema **dark (verde e preto)**, transições suaves, animações de scroll, partículas flutuantes, **toggle de idioma PT/EN em tempo real** e **modal interativo** para visualização e download de certificados. Hospedado gratuitamente via **GitHub Pages**.

---

## ✨ Funcionalidades

- **🌍 Bilíngue (PT/EN)** — alternância de idioma instantânea sem recarregar a página, com preservação do conteúdo original para múltiplas trocas
- **✨ Animações de scroll** — elementos surgem conforme o usuário rola (Intersection Observer)
- **🟢 Partículas flutuantes** — efeito visual dinâmico na seção hero, geradas via JavaScript
- **🖼️ Modal de certificados** — clique em qualquer certificado para abrir a imagem em tela cheia com botão de download
- **📊 Skill bars animadas** — barras de progresso que preenchem ao entrar na viewport
- **📅 Timeline interativa** — experiências com pontos pulsantes e linha gradient
- **🎮 Shimmer effect** — brilho desliza sobre os cards de skills e certificados no hover
- **📱 100% responsivo** — adaptado para mobile, tablet e desktop
- **☰ Menu mobile** — hambúrguer com overlay para telas pequenas
- **⌨️ Atalhos de teclado** — ESC fecha o modal de certificados
- **🖼️ Placeholder inteligente** — se a foto ou certificado não for encontrado, exibe um aviso elegante indicando o nome do arquivo esperado
